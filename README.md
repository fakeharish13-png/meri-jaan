## 🚀 Live Deployment
Easily deployed on **GitHub Pages**, **Vercel**, or **Netlify**.

### Enable GitHub Pages:
1. Go to repository **Settings** → **Pages**.
2. Under **Branch**, select `main` / `root` and click **Save**.
3. Your site will be live instantly!
